# Website Portofolio Kelompok

## 1. Goal (Tujuan Proyek)

Membangun sebuah website portofolio yang berfungsi sebagai media untuk menampilkan identitas, profil, kemampuan, pengalaman, serta hasil karya anggota kelompok secara profesional dan terstruktur.

**Indikator Keberhasilan:**
- Website dapat menampilkan informasi profil dan portofolio anggota kelompok secara lengkap.
- Pengunjung dapat menemukan informasi yang dibutuhkan dengan mudah melalui navigasi yang jelas.
- Website memiliki tampilan responsif dan dapat diakses melalui desktop maupun perangkat mobile.
- Setiap proyek atau karya dapat ditampilkan dengan informasi dan dokumentasi yang relevan.
- Website dapat dipublikasikan dan diakses secara online.

## 2. Users (Target Pengguna)

Website ini ditujukan kepada beberapa kelompok pengguna, yaitu:

1. **Recruiter atau HRD:** Pihak perusahaan yang ingin mengetahui profil, kemampuan, pengalaman, dan hasil karya anggota kelompok sebagai bahan pertimbangan rekrutmen.
2. **Perusahaan atau Klien:** Pihak yang ingin melihat kompetensi dan hasil pekerjaan untuk mempertimbangkan peluang kerja sama.
3. **Dosen dan Akademisi:** Pihak yang ingin melihat hasil proyek, kemampuan teknis, serta perkembangan kompetensi anggota kelompok.
4. **Masyarakat Umum:** Pengunjung yang ingin mengetahui profil dan karya anggota kelompok.

## 3. Kebutuhan (User Needs)

Pengunjung website membutuhkan informasi dan fitur berikut:

| No. | Kebutuhan | Deskripsi |
|---|---|---|
| 1 | Profil | Melihat nama, foto, deskripsi diri, dan latar belakang anggota kelompok. |
| 2 | Keahlian | Mengetahui kemampuan teknis maupun nonteknis yang dimiliki. |
| 3 | Pengalaman | Melihat pengalaman organisasi, pekerjaan, magang, atau kegiatan relevan. |
| 4 | Portofolio Proyek | Melihat hasil proyek yang pernah dikerjakan beserta deskripsi, teknologi, dan dokumentasinya. |
| 5 | Sertifikasi | Melihat sertifikat atau pencapaian yang pernah diperoleh. |
| 6 | Kontak | Menemukan informasi untuk menghubungi anggota kelompok. |
| 7 | Navigasi | Berpindah antarhalaman atau bagian website dengan mudah. |

## 4. Luaran (Project Deliverables)

### A. Fungsional
Website memiliki fungsi utama sebagai berikut:
- Halaman Home sebagai pengenalan website.
- Halaman About untuk menampilkan profil anggota kelompok.
- Halaman Skills untuk menampilkan kemampuan setiap anggota.
- Halaman Experience untuk menampilkan pengalaman.
- Halaman Portfolio untuk menampilkan proyek dan hasil karya.
- Halaman Contact untuk menyediakan informasi kontak dan tautan media profesional.
- Fitur navigasi yang memudahkan pengunjung mengakses setiap bagian website.

### B. Teknis
- Website dikembangkan menggunakan framework React.js.
- Menggunakan struktur kode yang terorganisasi dan mudah dipelihara.
- Menggunakan Git dan GitHub untuk version control serta kolaborasi pengembangan.
- Website dapat di-deploy ke layanan hosting agar bisa diakses secara online.

### C. Kualitas Umum
- **Responsive:** Tampilan menyesuaikan berbagai ukuran perangkat.
- **Usability:** Navigasi mudah dipahami dan digunakan.
- **Performance:** Website memiliki waktu pemuatan yang baik.
- **Consistency:** Desain, warna, tipografi, dan komponen memiliki konsistensi.
- **Accessibility:** Konten mudah dibaca dan elemen antarmuka dapat digunakan dengan baik.
- **Maintainability:** Kode mudah dikembangkan dan diperbaiki.

## 5. Scope (Ruang Lingkup Proyek)

### A. In Scope (Termasuk dalam Pengerjaan)
1. Analisis kebutuhan dan penentuan target pengguna.
2. Perancangan UI/UX menggunakan tools desain yang disepakati.
3. Pengembangan halaman utama website portofolio.
4. Pembuatan bagian profil, keahlian, pengalaman, proyek, dan kontak.
5. Implementasi desain responsif.
6. Integrasi tautan eksternal seperti GitHub, LinkedIn, dan email.
7. Pengujian fungsionalitas dan tampilan website.
8. Deployment website ke layanan hosting.

### B. Out of Scope (Tidak Termasuk dalam Pengerjaan)
1. Sistem autentikasi dan registrasi pengguna.
2. Dashboard admin untuk mengelola konten.
3. Sistem manajemen konten (CMS).
4. Database untuk penyimpanan data dinamis.
5. Sistem transaksi atau pembayaran.
6. Fitur komunikasi real-time seperti live chat.
7. Sistem rekrutmen atau pengiriman lamaran kerja secara langsung.

---

**Project Outcome:**

Menghasilkan sebuah website portofolio kelompok yang profesional, informatif, responsif, dan mudah diakses sebagai media representasi identitas, kompetensi, pengalaman, serta hasil karya seluruh anggota kelompok.
